Glossary

TTFB / TTFB-like proxy

TTFB is Time To First Byte, a standard web-performance term. Atom currently observes request start → response headers, so its card intentionally says TTFB-like proxy rather than claiming an exact Navigation Timing TTFB measurement.

DOM

DOM is Document Object Model: the browser's in-memory tree representing a web page. A DOM mutation is a structural change to that tree.

Long Task

A main-thread task lasting at least 50 ms. Long Tasks can delay input, scrolling, and rendering because much browser UI work shares that main thread.

Frame gap / jank

A frame gap is time between visual updates. Jank is the common performance term for visible stutter or sluggishness.

HTTP 429

The standard HTTP status Too Many Requests. It means the service refused a request under its current rate/admission limits.
