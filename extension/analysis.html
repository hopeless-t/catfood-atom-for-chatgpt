Glossary

TTFB / TTFB-like proxy

TTFB is Time To First Byte. Atom currently observes request start → response headers, so it deliberately says TTFB-like proxy rather than claiming exact Navigation Timing TTFB.

Style/layout tail

Style/layout tail is the late-frame style and geometry work exposed by Long Animation Frame timing. It is a direct browser timing signal and does not require a continuous DOM mutation observer.

Main-thread pressure

Uses LoAF blocking time on modern browsers and Long Task time as a fallback. Input and rendering may wait while the main UI thread is occupied.

Long Animation Frame (LoAF)

A browser frame that took unusually long. Atom stores only numeric attribution buckets — ChatGPT scripts, extension scripts, other scripts, and unattributed time — never script URLs.

Frame gap / jank

A frame gap is time between visual updates. Jank is visible stutter or sluggishness.

HTTP 429

The standard HTTP status Too Many Requests. Atom observes it; Boost does not attempt to bypass it.

All analysis and Boost settings are local. Compare similar workloads before drawing conclusions from baseline deltas.
