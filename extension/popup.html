CATFOOD Atom for ChatGPT

–
TTFB-like proxy
Server response wait — how long until ChatGPT starts replying.
–
API request burst
How many ChatGPT requests started together in the busiest second.
–
Interaction latency
Click / typing delay — how long the page took to react.
–
Max frame gap
Screen stutter — the longest pause between visual updates.
–
DOM mutations
Page update work — structural changes made to the page.
–
HTTP 429
Rate-limit errors — requests the service would not accept.
Terms, explained gently
TTFB-like proxyTTFB means “Time To First Byte.” CATFOOD Atom currently measures from request start until response headers arrive, so it is deliberately labeled TTFB-like rather than exact browser Navigation Timing TTFB. Smaller usually means less waiting before a response begins.
API request burstA cluster of requests starting close together. Atom reports the busiest one-second window in the latest 60 seconds.
Interaction latencyThe time associated with a click, key, pointer, or input interaction. High values are the “I pressed it, why did nothing happen?” feeling.
Max frame gap / jankBrowsers normally update the screen repeatedly. A long gap means the screen paused. “Jank” is the common performance term for visible stutter or sluggishness.
DOM mutationsDOM means Document Object Model: the browser's in-memory tree for the page. A mutation is a structural change to that tree. Many mutations are not automatically bad, but they can represent extra browser work.
HTTP 429The standard HTTP status “Too Many Requests.” It means the service refused that request under its current rate/admission limits.
Long TaskA browser main-thread task lasting at least 50 ms. While the main thread is busy, input and rendering may have to wait.
