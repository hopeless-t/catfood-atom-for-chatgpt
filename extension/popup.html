What do these numbers mean?
Server response waitFrom a ChatGPT request starting until its response headers arrive. This is a TTFB-like measurement: lower usually means less waiting before the response begins.
Requests at onceThe busiest one-second window in the last 60 seconds. A high value means many ChatGPT requests started close together.
Click / typing delayThe slowest observed click, key, pointer, or input interaction in the last 60 seconds. Higher values mean the page felt less responsive.
Screen stutterThe longest observed gap between animation frames. A large gap means the screen stopped updating smoothly for longer.
Page update workHow many structural DOM changes were observed in the last 60 seconds. DOM is the browser's in-memory tree representing the page. More changes are not automatically bad, but very high activity can mean more browser work.
Rate-limit errorsHTTP 429 means the service rejected a request because too many requests were accepted for the current limit or admission state.
Main-thread long taskA continuous browser task lasting at least 50 ms. While it runs, clicks, typing, rendering, and scrolling may have to wait.
JankA general web-performance term for visible UI sluggishness or stuttering, often associated with long main-thread work or blocked rendering.

All cards summarize the most recent 60 seconds. Local metrics only. Conversation content is not collected.
